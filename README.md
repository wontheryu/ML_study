현대 머신러닝의 8대 핵심 섹터를 정복하며, 각 폴더에는 데이터 분석 전문성을 보여주는 main.ipynb와 README.md가 포함됩니다.

단계	섹터 (Sector)	핵심 주제 및 모델	학습 상태

06	Boosting Models	XGBoost, LightGBM, CatBoost 성능 최적화	⬜ 대기
07	SVM & KNN	Kernel Trick, 거리 기반 고차원 데이터 처리	⬜ 대기
08	Clustering & PCA	K-Means, 차원 축소 및 군집화 비즈니스 활용	⬜ 대기
