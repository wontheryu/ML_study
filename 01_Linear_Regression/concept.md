# 📘 Concept: Linear Regression (선형 회귀)
선형 회귀는 독립 변수()와 종속 변수() 사이의 선형 상관관계를 모델링하는 가장 기초적이면서도 강력한 분석 기법입니다.

## 1. 선형 회귀의 종류

### 1) 단순 선형 회귀 (Simple Linear Regression)

하나의 독립 변수와 하나의 종속 변수 간의 관계를 분석합니다.


### 2) 다중 선형 회귀 (Multiple Linear Regression)

여러 개의 독립 변수를 사용하여 종속 변수를 예측합니다. 실무에서 다루는 대부분의 데이터는 다중 회귀에 해당합니다.
---

## 2. 수학적 원리와 비용 함수

모델의 목표는 실제값과 예측값의 차이(오차)를 최소화하는 최적의 가중치()와 절편()을 찾는 것입니다.

*  비용 함수 (Cost Function): MSE (Mean Squared Error) 
오차의 제곱을 평균내어 모델의 성능을 수치화합니다. 이 값이 작을수록 모델의 예측력이 좋습니다.

---
## 3. 선형 회귀의 4대 기본 가정
모델의 신뢰성을 보장하기 위해 데이터가 다음의 가정을 만족하는지 확인해야 합니다.

1.  선형성 (Linearity):  와  사이에 직선적인 관계가 존재해야 함.
2.  독립성 (Independence):  다중 회귀에서 독립 변수들끼리 서로 독립적이어야 함.
3.  등분산성 (Homoscedasticity):  잔차(오차)의 분산이 모든 변수 수준에서 일정해야 함.
4.  정규성 (Normality):  잔차의 분포가 정규 분포를 따라야 함.

---

## 4. 핵심 평가 지표 (Evaluation Metrics)

| 지표 | 풀임 (Full Name) | 특징 및 해석 방법 |
| --- | --- | --- |
|  MSE  | Mean Squared Error | 오차 제곱 합의 평균. 클수록 예측이 많이 틀림. |
|  RMSE  | Root MSE | MSE에 루트를 씌움. 실제 타겟 단위와 동일하여 해석이 직관적임. |
|  MAE  | Mean Absolute Error | 오차 절대값의 평균. 이상치(Outlier)에 덜 민감함. |
|    | 결정계수 | 모델이 데이터의 분산을 얼마나 설명하는가 (0~1). 1에 가까울수록 우수. |
|  Adj   | 수정된 결정계수 |  [다중회귀 필수]  변수 개수가 늘어남에 따라 가 가짜로 상승하는 것을 방지. |

---

## 5. 다중 회귀의 장애물: 다중공선성 (Multicollinearity)

독립 변수들끼리 서로 강한 상관관계를 가질 때 발생하는 문제입니다.

*  문제점:  회귀 계수(Coefficient)의 변동성이 커져 모델의 해석력이 떨어지고 신뢰할 수 없게 됨.
*  판단 지표 (VIF):   VIF(Variance Inflation Factor)  지수가  10 이상 이면 해당 변수는 다중공선성 문제가 있다고 판단하여 제거하거나 PCA 등으로 처리해야 함.

---
## 6. 주요 용어 정리 (Terminology)

*  Coefficient (계수):  독립 변수 가 1단위 변화할 때 종속 변수 에 미치는 영향력.
*  Intercept (절편):  모든 독립 변수가 0일 때의 기본  값.
*  P-value:  해당 변수가 통계적으로 유의미한지 판단하는 지표 (통상  0.05 미만 일 때 유의미).
*  Residual (잔차):  실제값과 모델이 예측한 값의 차이 ().
